# Publication figures

Elegant, publication-ready figures for the k-plexity application note (PNG + SVG).

| file | what |
|---|---|
| `kplexity_examples` | example curves — bacterium / plant / invertebrate / vertebrate, single + double sigmoid fits |
| `fig_qc_assemblies` | **Use case 1 — assembly QC**: the asymptote separates assemblies of the same genome by quality (human + Arabidopsis panels) |
| `fig2_annotated` | k-plexity across 326 EDTA-annotated DToL genomes: L2/(L1+L2) vs EDTA TE (ρ=0.92), k0_1 vs log4(genome) (ρ=0.94) |

Generated by the scripts in the `kplexity_analysis` repo (make_readme_figures.py, make_fig_qc.py, make_fig2_annotated.py).

# Publication figures

Elegant, publication-ready figures for the k-plexity application note (PNG + SVG).

| file | what |
|---|---|
| `kplexity_examples` | example curves — bacterium / plant / invertebrate / vertebrate, single + double sigmoid fits |
| `fig_qc_assemblies` | **Use case 1 — assembly QC**: the asymptote separates assemblies of the same genome by quality (human + Arabidopsis panels) |
| `fig2_annotated` | **Use case 2 — repeat screening** across 326 EDTA/TRASH-annotated DToL genomes: curves by clade; L2/(L1+L2) vs EDTA TE fit per clade (r=0.87–0.93); asymptote vs TRASH satellite |
| `fig_D_satellites` | **Use case 3 — diagnostics**: k-plexity curves for human satellite families (α, HSat1/2/3, β, γ); asymptote vs total satellite across 24 chromosomes (r=−0.97, R²=0.94) |
| `fig_S4_hsat_vs_alpha` | Supp: asymptote vs HSat (R²=0.97) vs vs alpha-satellite (R²=0.01) — the asymptote tracks HSat, not alpha |
| `chr19_alu_kplexity` | Supp: chr19 Alu-only k-plexity reproduces the k0_2 second sigmoid (k50≈27≈chr19 k0_2; k50 vs divergence r=−0.88) |
| `chr18_alu_kplexity` | Supp: the same for chr18 (6.5 Mb / 24.6k Alus, older: k50≈25, r=−0.83) — parallel to chr19 |
| `fig_alpha_beta_map` | Supp: map of alpha- vs beta-satellite across the 24 CHM13 chromosomes (ideogram + per-chromosome content) |
| `merqury_vs_kplexity` | Supp (use case 1): k-plexity asymptote vs Merqury QV, AUC vs completeness, on Arabidopsis assemblies — read-free quality proxy |
| `fig0_information` | Supp (sketching): where along k each of the six fit parameters (L1, s1, k0_1, L2, s2, k0_2) is determined — a narrow first rise and a broad second transition — and where each k-schedule puts 25 k |
| `fig2_frontier` | Supp (sketching): drift of the six fit parameters and share of genomes recovered (all six within 10% / 5%) vs k-budget (10–75 k), spacing-weighted fits; size-anchored recovers ~93% of genomes from 20 k |
| `fig7_violins` | Supp (sketching): per-genome six-parameter drift by schedule and budget |

All figures use Arial (SVGs editable). Generated by scripts in the `kplexity_analysis` repo (make_readme_figures.py, make_fig_qc.py, make_fig2_annotated.py, make_fig_D.py, make_fig_S4.py, analyze_chr19_alu.py, plot_sketching_results.py, plot_merqury_vs_kplexity.py).

# Publication figures

Figures for the kplexity application note (PNG + SVG; Arial, editable text), all fitted with the kplexity model
`y(k) = B(k)·[A − S·e^(−λ(k−k0))]` as shipped in this package.

| file | what |
|---|---|
| `fig1` | **Figure 1.** (a) obtaining and reading the curve: k-mers, counting, the curve, the fit and its three terms; (b) case A, assembly QC without reads (human and *Arabidopsis* assemblies, A in the legends); (c) case B, repeat screening across 326 annotated DToL genomes (clade medians and middle 50%; S vs EDTA transposon content); (d) case C, 1 − A vs satellite across the 24 CHM13 chromosomes and isolated satellite families |
| `model_diagram` | the model term by term: chance collisions, + identical copies (plateau A), + near copies (gap S closing at rate λ) |
| `figS1_model` | S1. the model: random-sequence curve, k0 vs log₄G, fit error of nested models, the residual left by collisions + plateau, gain vs S, extrapolation |
| `figS2_annotation` | S2. the parameters against annotation across the tree of life: S vs TE, other drivers, 1 − A vs satellite, Pagel's λ, PGLS, the exception genomes |
| `figS3_chromosomes` | S3. CHM13 chromosomes and repeat families (S vs Alu, 1 − A vs HSat, chr18 vs chr19, Alu subfamilies, rDNA) and *Arabidopsis* rDNA vs CEN178 |
| `figS4_simulations` | S4. simulated genomes: recovery of divergence, S and 1 − A; mixtures of young and old copies |
| `figS5_sketching` | S5. sketched k schedules (`kplex run --sketch`): drift vs number of k values, per parameter, chr18/chr19 |
| `figS6_assembly_qc` | S6. assembly QC: A vs Merqury QV and completeness, contigs vs scaffolds, run time on CHM13 |

Generated by `make_figure1_v2.py` and `make_supp_figures_v2.py` in the `kplexity_analysis` repo.
